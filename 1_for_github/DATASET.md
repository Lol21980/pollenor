# Паспорт набора данных

Данные: World Bank, три CSV файла про население и экономику стран.
Лежат в `data/raw/`, всего 3 145 725 строк и 11 столбцов.
Кодировка UTF-8, разделитель точка с запятой.

## Столбцы

| Название | Что это | Тип | Комментарий |
|---|---|---|---|
| Страна | название страны | текст | всего 265 стран |
| Код страны | код из 3 букв | текст | например AFG |
| Регион | регион мира | категория | у итоговых строк (Africa и т.п.) пусто - так и должно быть |
| Группа дохода | богатая/бедная | категория | тоже пусто у итогов |
| Код показателя | код типа SP.POP.TOTL | текст | всего 1486 штук |
| Название показателя | расшифровка | текст | |
| Тема показателя | раздел | категория | |
| Определение | длинное описание | текст | повторяется, поэтому вынес в справочник |
| Год | 1960-2025 | число | |
| Значение | само число | число | главная колонка |
| Сноска | примечание | текст | почти везде пустая (92%), я ее удалил |

## Какие проблемы нашел

1. Каждый файл ровно 1048575 строк. Это лимит экселя, значит данные обрезаны и это уже не исправить.
2. В первом файле значения типа "мар.73", "янв.74". Это эксель превратил числа 3.73 в даты (март 73-го). Я написал функцию которая чинит это обратно. После починки пустых осталось всего 0.1%.
3. Регион и доход пустые у строк-итогов - это не ошибка, у них и не должно быть региона.
4. Сноска пустая на 92% - удалил столбец.
5. Единицы измерения разные (миллиарды, проценты, доллары в одной колонке), поэтому средние по всей колонке считать бессмысленно, только внутри одного показателя.
6. Дубликатов нет (проверил, удалилось 0 строк).
